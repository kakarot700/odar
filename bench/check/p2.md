In Python, functools.cache is a simple lightweight unbounded function cache, sometimes called memoize ([docs](https://docs.python.org/3/library/functools.html)). The functools.cache decorator evicts the least recently used values once it reaches 128 entries ([docs](https://docs.python.org/3/library/functools.html)). The cache is threadsafe so that the wrapped function can be used in multiple threads ([docs](https://docs.python.org/3/library/functools.html)).
