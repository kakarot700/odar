# ODAR Check: Chrome extension

Check the citations in any AI answer or article from your browser.

1. Run the ODAR server (`odar serve`) or use your hosted instance.
2. In the web app open **API & privacy**, create a key.
3. Chrome → `chrome://extensions` → Developer mode → **Load unpacked** → pick this folder.
4. Open the extension's Settings, enter the server URL and key.

Use: select text on a page (ChatGPT, Perplexity, a news article), right-click → **Check citations with ODAR**,
or open the popup and paste / **Use whole page**. Links in the selection are kept so citations can be opened.
